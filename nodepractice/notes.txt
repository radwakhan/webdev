const http=require("http") this import built in http module, use to create http server
http.createServer((req,res)=>{...}) creates the server. req,res is callback function that
handle incoming request, req- contain info about client req.
                         res- allow to construct and send response to client

res.writehead(200,{..}) set code success and declare res content type is plain text.
              more-text/plain, text/html, application/json
res.end("..") send response body and end the response

server.listen(3000,...) it tells to listen incoming connection on port 3000
